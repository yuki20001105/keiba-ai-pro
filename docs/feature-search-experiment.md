目的はレース平均Spearman順位相関の改善。速度回帰ではRMSEも比較する。
買い目・回収率はモデルの選定から切り離す。最大200試行、3段階の有限探索。
全ての組み合わせの最適解・回収率100%以上・未知期間への再現は保証しない。

## 固定する条件

- 親実験 `20260919-jra-safe-v1` の安全データ453,777頭・32,514レースを変更しない。
- 72特徴量に履歴のレース内相対値16、傾向4、欠損3、適性変化2、履歴量4を追加（計101）。
- 現在レースの着順・タイム・オッズ・人気・払戻は入力に使用しない。
- 2021/2022年だけを探索に使い、各評価年の前年までで学習。
- 特徴量選択・条件選択・seed固定後、2023–2025年と2026年を別々に確認。
- 確認期間は以前の実験で既に利用済み。完全未見の最終評価とは呼ばない。
- 速度偏差のRMSEは学習期間を変えると尺度も変わるため、横断比較はm/s単位のRMSEを用いる。

## 改善サイクル

1. 元72/拡張101、LambdaRank・rank_xendcg・正規化順位回帰・速度回帰を比較。
2. 拡張順位モデルから各特徴量を一つずつ除き、101回再学習。
3. 開発期間での改善と年別安定性から候補を絞り、ペア/累積除去を最大24件。
4. 木の深さに関係する葉数、正則化、学習率、ラウンド数、学習開始年を最大18条件。
5. 最良条件で16特徴量の再除去＋12組み合わせを再評価。
6. seed 7/2026を頑健性確認に使用（seedの良い結果を選び直さない）。
7. 選定仕様・結果ハッシュを固定し、基準・選定・回帰対照を全評価。

主選定は順位相関、1e-6以内の同点は少ない特徴量、年別最悪順位相関で判断。
回帰候補の順位相関と物理速度RMSEのPareto集合も保持。SHAP単独では特徴量を削除しない。

## 買い目の評価

モデルを固定後、単勝の順位・オッズ帯・スコア差・人気除外など最大60ルール。
モデルを調整した探索年と同じ2021/2022年で買い目を選ぶため、その成績には選択バイアスがある。
2023–2025年と2026年を確認に使用し、その結果でルールを選び直さない。
100円固定、購入数・日数・年別安定性・日単位bootstrap下限も考慮する。
観測時刻不明のオッズは最終市場情報による参考値であり、そのまま実購入時に再現できる検証ではない。
未確認払戻を0やオッズで埋めず、全体の回収率を未確定とし、確認済み部分は別記する。
馬連・馬単・ワイド・三連複・三連単は完全な時刻付きオッズと公式払戻が整うまで検証済みとは扱わない。

## 実行と保全

`python-api/.venv/Scripts/python.exe scripts/run_model_search.py prepare --root reports/generated/model-experiments/20260919-feature-search-v1`

`python-api/.venv/Scripts/python.exe scripts/run_model_search.py run --root reports/generated/model-experiments/20260919-feature-search-v1`

`run`はCPU最大2ワーカー（各4スレッド）で順次並列投入。空きRAMが不足すれば待機。
現行LightGBMビルドはGPU learner未対応。今回のCPU計測が短いため環境を入れ替えず実行。
各候補は隔離プロセス・lease・成果物ハッシュで保護し、停止/状態不明時の無断再投入は行わない。
`status`で確認、`cancel`でこの実験の停止要求。アプリのPythonは停止しない。
既存DB・以前の実験・使用中モデルを変更しない。最終候補の年別モデルは実験フォルダへ保存する。
スクリーニング段階は予測/指標/仕様/ハッシュを保存し、全候補のモデル本体は保存しない。

[相関した特徴量の重要度の注意](https://scikit-learn.org/stable/auto_examples/inspection/plot_permutation_importance_multicollinear.html)。
