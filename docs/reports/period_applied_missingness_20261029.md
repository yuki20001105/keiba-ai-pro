# 全期間への履歴修正・推定補完適用後の欠損数 — 2026-10-29

**今回は修正を実際に全対象行へ適用した。72特徴量の欠損は
3,112,889 → 2,926,883 → 2,409,053セル。703,836セル（22.61%）減ったが、欠損0ではない。**

## 対象と適用内容

既存の凍結研究集団32,826レース・458,095行を、同一行・同一順序・同一72特徴量で比較した。
収録範囲は2016-01-05〜2026-10-17。2016〜2026年の全開催・全馬の収録を保証するものではない。
過去走の参照開始日は2013-01-01。新規通信・再取得は今回行っていない。

1. **履歴参照の修正:** レース単位の完全性フィルターで落ちていた、個別には適格な正常走を参照へ戻した。
   履歴は590,485行・41,923レースから632,560行・45,053レースへ拡張した。
   学習・評価対象のレース集団は増やさず、当日・未来の結果を参照せずに派生特徴量を再計算した。
   186,006セルを復元し、新たな欠損は0セル。既存の非欠損値も7,978,956セル更新された。
2. **推定補完:** 同条件の保存済み参照件数が0で、同馬の同じ芝・ダート区分には過去実績がある場合、
   コース別・距離帯別の勝率／3着以内率／平均速度を、その同馬の実績でバックオフした。
   517,830セルを補完し、6種類の補完フラグ・セル単位の出典列・参照件数を保存した。
   条件別出走数0を実測出走数へ書き換えてはいない。

**全馬の公開履歴を網羅確認したわけではない。**
新しい研究用契約は `research-individual-history-surface-backoff-v1`。
「保存済み適格履歴に同条件がない」ことを「公開履歴でも真の初条件である」とは断定しない。
以前の有馬記念の出典監査済み補完契約を緩めたり、同じ承認として流用したりしていない。
モデル精度・利益の改善や本番採用を示す実験ではない。

## 残る欠損の具体的な理由

| 保存済みデータ上で確認できる状態 | 欠損セル |
|---|---:|
| 過去走0件のため、前走・間隔・直近平均など21指標が未算出（46,351行） | 973,371 |
| 過去走が2件未満のため、2走前の4指標が未算出（90,826行） | 363,304 |
| 芝・ダート別の参照実績がなく、同区分・コース別6指標を補完できない（72,982行） | 437,892 |
| 距離帯別の参照実績も芝・ダート別の補完元もなく、3指標が未算出（53,457行） | 160,371 |
| 騎手・調教師・父・母父は識別できるが、その集計対象で過去実績が0件 | 5,784 |
| 父・母父の識別が不足し、各3集計指標を作れない（各78,014行） | 468,084 |
| レースクラスが未確定 | 244 |
| 過去走自体はあるが、参照する上がり3Fがなく直近平均3指標が未算出 | 3 |
| **合計** | **2,409,053** |

表のセル分類は相互排他的。同じ馬の行が異なる指標群に現れるため、行数は足し合わせない。
うち1,940,722セルは保存履歴の参照件数不足、468,331セルは識別・入力不足等。
初出走・初条件と、公開過去走の未収録・品質選別・参照開始前の左切断は全馬分離できていない。
この件数だけから「再取得しても存在しない」「すべて取得失敗」とは判定しない。
識別・クラス不足も、全件再取得後の残存数ではなく、今回読み取った凍結入力での残存数である。
馬に過去走がない場合の人口平均等による追加補完は今回導入せず、根拠不足のNaNを残した。

## 成果物と運用上の境界

正本:
`reports\generated\data-quality\feature-gap\period-applied-2016-2026-20261029-v2`

- `contract.json` / `artifacts.json`: 固定した入力・コード・特徴量・成果物のハッシュ。
- `history-observations.parquet` / `history-selection.json`: 実際に参照した個別適格履歴。
- `history-rebuilt.parquet` / `applied-dataset.parquet`: 履歴修正後／補完後の同一集団。
- `model-inputs.parquet`: 許可済み72特徴量と6補完フラグだけの研究用入力。結果・IDを含めない。
- `imputations.parquet`: 各補完セルの馬・レース・参照列・件数・推定値。
- `yearly-missingness.json` / `feature-changes.json` / `remaining-missingness.json`: 年別・列別件数と残存状態。
- `verification.json` / `replay-verification.json`: 実行時照合／独立した保存結果の再集計。

独立検証では元の特徴量生成関数を呼ばず、過去日検索・日別累積集計で56派生特徴量を全458,095行再計算し、
残る16基本特徴量の不変、11年度・全72特徴量の欠損数、全517,830補完セルとフラグを照合した。
残存理由の相互排他的な合計も2,409,053セルと一致した。

v1は残存監査メタ情報の `imputation_applied` が監査関数の既定値falseのままになったため、
既存成果物を上書きせずv2で補完済みデータとして再生成した。集計・補完アルゴリズムは同じ。
旧レポートの3,112,889セルは適用前の履歴記録として維持する。
元DB・凍結対照・本番モデル・正式購入ポリシーは変更していない。
保留中の血統一括取得も再開していない。
