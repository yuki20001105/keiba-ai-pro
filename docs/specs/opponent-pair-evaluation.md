# A軸・相手ペアの少点数比較 v1

## 位置付け

保存済みTEST予測から、相手順位と1〜6点の買い方を有限比較する研究用評価。
本番API・購入許可・現行モデルを変更しない。出力は常に
`reference_only=true`, `purchase_eligible=false`。
保存済み単勝オッズには発走前取得の保証がなく、基礎モデルの確率検証も未承認。

## 固定条件

- 元の数値的勝負候補630件から2024年のwarmup78件を除いた552件を共通母数とする。
- 既存の四半期更新予測による `P(Aが3着内) >= 0.65` を通過した355件だけ購入。
  モデル再学習・閾値調整・レース選別の再探索は行わない。見送り197件も台帳に残す。
- Aは単勝オッズ最小の馬。同オッズは馬番の小さい順。
- 相手集合はAを除いたAI勝率上位最大5頭。必要なら全体AI6位まで補充する。
  実際に5頭立てなら相手は4頭であり、存在しない馬を追加しない。
- この集合をAI勝率順（B1〜B5）、または `AI勝率×単勝オッズ` 順（H1〜H5）に並べる。
  同スコアは馬番順。Bは**A除外後の順位**であり、全体のAI順位ではない。
  Hのスコアは組合せ券の期待値ではない。

各順位方式で全10ペアを選び、ワイドはなし／一人目／二人目／両方、
三連複はなし／1点、三連単はAの1・2・3着固定の任意の位置集合を比較する。
各固定位置には相手2頭の両順を含める。合計1〜6点だけ残すため、
53構成×10ペア×2順位＝1,060設定となる。

使用する順位が存在しなければ、そのレースの当該構成を見送る。
使用しない順位の欠落では見送らない。ワイド・三連複の馬番は昇順、
三連単の馬番順序は保持する。確認済み公式払戻を持たない券種は精算エラーとし、
「未確認」を外れ0円にはしない。

初期予算100万円、1レース上限1,500円。1点当たりは
`100 * floor(1500 / (100 * 点数))` 円。
1〜6点の単価は順に1,500／700／500／300／300／200円。
追い上げ・複利・借入なし。未使用資金は現金として残す。

## 選定と報告

全期間の回収率順位は**事後的な参考順位**。購入内容・金額の全期間重複も開示する。
実績を伴う参考順位は購入150件以上・購入日20日以上・的中20レース以上に限定する。

別途、2025年だけで購入150件以上・購入日20日以上・的中10レース以上を満たす
構成から、平均回収率最大と日付bootstrap回収率10パーセンタイル最大を選ぶ。
同値は少点数、次にmethod ID辞書順。選定スコアが100%以下なら見送り。
下側スコアは500回、seed=20261103。2026年には構成を固定して適用し、
2026年の結果や全期間重複判定を2025年選定に使わない。

詳細表には年別成績、的中レース数、日次最大ドローダウン、
最大払戻レースの払戻だけを0円にした回収率、日付bootstrap95%区間
（1,000回、同seed）を残す。区間は多数比較補正済みではない。
以前から閲覧済みのTESTを再利用するため、2025→2026も真の未見検証ではなく擬似OOT。

## 再実行

リポジトリルートで、**未使用の出力先**を指定する。

```powershell
.\python-api\.venv\Scripts\python.exe -X utf8 scripts\evaluate_market_axis_pairs.py `
  --output reports\generated\race-selection\opponent-pairs-reproduction
.\python-api\.venv\Scripts\python.exe -X utf8 scripts\verify_market_axis_pairs.py `
  --output reports\generated\race-selection\opponent-pairs-reproduction
```

入力親ディレクトリは `--study-root` で変更できる。7入力の相対名とSHA256は
評価CLIの `SOURCES` に固定し、不一致・欠落・既存出力先を拒否する。
新規checkoutだけでは凍結済み研究データが揃わない場合がある。
実行環境のバージョン、ソースhash、仕様、全設定、全レース精算、
重複排除したレース別購入内容、選定証拠、集計を保存する。
独立verifierは本体の買い目生成・精算・選定関数を使用しない。

これは**保存済み予測・判定からの評価再現**であり、荒れ度モデルの再学習、
移動可能な学習データkit、本番推論への統合を完了するものではない。
別モデルの予測や別のgateへ結果をそのまま流用しない。
